# Code of conduct

## Expected behavior

Be respectful, specific, and patient. Critique code and decisions rather than people. Keep reports focused on reproducible behavior. Respect privacy: never post another person's memory data, private paths, repository names, credentials, or identifying logs.

## Unacceptable behavior

Harassment, threats, discrimination, deliberate disclosure of private data, and sustained disruption are not accepted.

## Enforcement

For ordinary moderation, contact the maintainer through the repository owner's GitHub profile without publishing sensitive details. Use GitHub's abuse-reporting tools for threats or platform abuse. Maintainers may edit, hide, or remove contributions and may temporarily or permanently restrict participation.

This policy applies in repository issues, pull requests, discussions, release comments, and other project spaces.
